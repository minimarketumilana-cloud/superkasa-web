Receipt printer, barcode scanner and cash drawer

Direct receipt printing needs a printer with ESC/POS commands, the scanner should work as a USB keyboard and the cash drawer plugs into the printer. This guide describes how to connect them and what to do when a receipt does not print.

We have not yet tested all types of printer, so we do not give a list of verified models. ESC/POS is the language of receipt printers. Before you buy a cheap printer, check with the seller that it supports this language. Label printers (Zebra, TSC, Brother, Dymo) have their own language. Receipts will not go to them directly.

How to connect the printer

Open the wizard in Menu → Printer, or in Admin → Devices → Add a printer. It offers only what is possible on your device. A cashier sees fewer options than the owner.

Driver in Windows

For a USB printer, the driver must be installed first.

  1. Connect the printer with a USB cable and switch it on.
  2. Wait until Windows installs it. An Epson TM needs a driver from the Epson website (EPSON Advanced Printer Driver). Other brands have a driver on a CD or on the seller's website.
  3. In Windows, set the receipt printer as the default printer.
  4. In the POS wizard, choose Print via the browser dialog and tap Save. The print window opens right away with a test slip.
  5. In the print window, choose the receipt printer and set Margins to None. The browser remembers the choice.

Printing without a dialog

Nothing is downloaded. You just open the POS with a Chrome shortcut that prints straight to the default printer without the print window.

  1. In Windows, set the receipt printer as the default printer.
  2. Right-click the Google Chrome shortcut and choose Properties.
  3. In the Target field, enter "C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk-printing --user-data-dir="C:\SuperKasaChrome" followed by your shop's address.
  4. Always open the POS with this shortcut. Sign in once the first time.

SuperKasa then opens in its own Chrome window, separate from your normal Chrome. You will also find the steps in the POS under Admin → Peripherals → Printing without the confirmation window. Only the owner sees Admin → Peripherals.

Bluetooth

  1. Switch on the printer and switch on Bluetooth on the phone. If Android asks, switch on location too.
  2. Tap Connect printer and select it in the list.
  3. A test prints.

After a page refresh, a Bluetooth printer does not reconnect by itself. The POS shows a Printing failed window. Tap Connect printer. On iPhone and iPad, Bluetooth printing from a browser does not work.

Network printer

A browser cannot send data straight to a network printer. Add the printer to Windows (Settings → Printers & scanners) and print to it like any other Windows printer – without a dialog or through the print window.

Cash drawer

The drawer plugs into the receipt printer, not into the computer. The drawer cable goes into the printer port marked DK. A network (internet) cable looks similar but will not open the drawer. Do not plug it into the DK port.

Printing through the browser window (the usual setup on a computer): the Windows printer driver opens the drawer with every print.

  1. Connect the drawer cable to the DK port on the printer.
  2. In Windows open Settings → Printers & scanners, choose the receipt printer and Printing preferences. In the driver, switch on opening the cash drawer at the start of printing. In the Epson driver the option is on the Peripherals → Cash Drawer → Start of Document tab.
  3. In the POS open Admin → Peripherals → Cash drawer, switch on The cash drawer is plugged into this computer's printer and click Test the drawer.

With a receipt the drawer opens by itself. Without a receipt (the Drawer button, a cash payment without printing) the POS sends a short blank print that opens the drawer. The driver opens it with every print, so also with a receipt for a card payment.

A printer connected directly (Bluetooth, USB or a serial port in the browser): in the printer wizard, tick Open the drawer on cash payments (drawer plugged into the printer). The POS then opens the drawer only for cash.

Each manual opening of the drawer is recorded.

Barcode scanner

A USB scanner works as a keyboard. You just plug it in and nothing is installed.

  1. Plug the scanner into USB.
  2. Open Menu → Barcode scanner.
  3. Scan a code from any package.
  4. The POS shows The scanner works and the code.

The scanner should send Enter after the code. If it does not, the POS still manages, only a little more slowly. In the scanner's manual, look for the option “Enter suffix”. A Czech keyboard is not a problem. The POS converts the characters ě, š, č into digits by itself.

If the scanner writes strange characters, switch it to “USB keyboard (HID)” mode according to its manual. The POS does not use “COM / serial port” mode. A wireless scanner needs its USB receiver.

Tablet or phone and printing at the main till

On phones and tablets, the camera reads the codes. You pair a Bluetooth scanner in the phone's settings.

Selling on a phone with the printer at the main till? The main till must have the printer set up first.

  1. On the phone, open Menu → Printer.
  2. Choose Print on the main till's printer.
  3. Select the device that the printer is at.
  4. Switch on the drawer at the main till with the option Open the main till's drawer on cash payment.
  5. Tap Use it and print a test.

If the main till has its printer connected through Bluetooth or USB in the browser, it must have the POS open. In the background is enough. Otherwise the phone shows “The main till is not open”. There is more in the guide The POS on a phone or tablet.

Printing price labels

Price labels are in the Shop plan. A hairdresser or café does not have them in the POS. The owner or a manager prints them.

  1. Open Admin → Print price labels.
  2. Select the goods. You can find changed prices with the Price changed since filter.
  3. In the Size field, choose an 80 or 58 mm roll.
  4. Leave Price per kg / l (required by law) switched on.
  5. Tap Print labels.

Under Other printers (label printer, A4) you will find thermal labels and A4 sheets. Label printers print through the browser window. Set the label size in the printer driver, for example 58 × 40 mm. Colour designs print only on A4.

For price labels to go directly to the receipt printer, Also print price labels here must be ticked in Admin → Devices → Set up.

Selling without internet through the main tillThe receipt prints through the browser window. Without internet, the main till does not accept printing from a phone.

Invoices print on A4. On a POS running in full screen (kiosk) an invoice would go to the narrow receipt printer, so the POS offers it for download with the Download invoice button. Open the file and print it on an A4 printer.

Frequently asked questions

Does SuperKasa work with my printer?

Direct printing needs a printer that understands ESC/POS commands. We have not tested all types, so check with a test print during the 10 free days. Without a receipt printer you can print through the browser window.

Do I need a driver for the scanner?

An ordinary USB scanner does not need a driver. It must be in USB keyboard (HID) mode. You can try it in Menu → Barcode scanner.

Can the drawer open without a printer?

No. The drawer opens through the receipt printer it is connected to.

Can I print from an iPhone?

An iPhone does not connect a Bluetooth printer in the browser. Use the printer at the main till, or an Android tablet.

Must I use a receipt printer for price labels?

No. Price labels can also go to a label printer through the browser or to an ordinary printer on A4 sheets.
